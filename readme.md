# Jargon Renex

**renex** = **ren** + **regex**

## Overview
Jargon Renex is a Windows command-line tool for renaming files with regular expressions.

It uses Perl-compatible regular expression syntax, like `s/old/new/i`

By-default, nothing is renamed. You can either:
* Run a renex command, review the proposed changes, then re-run the command with `-yes`
* Run a renex command with `-ask` to be prompted before renaming files.

## Details

Hopefully, it goes without saying you should be familiar with Perl-style regular expressions to use this tool. See [perlretut](https://perldoc.perl.org/perlretut)

By default, only the **base filename** of a file is processed with the regular expression. For a file such as `c:\path\to\myfilename.ext`, the regex will only affect `myfilename`. To include paths and file extensions in processing, you can use the `-path` and `-ext` options.

Filenames to be processed can be specified on the command line, or fed through stdin via the `-stdin` option.

Long filenames (exceeding Windows MAX_PATH length) are supported when using absolute path names.

Regex captures are supported in the same way as Perl, using parens `()` to capture a match, and dollar-sign variables such as `$1` or `$2` to reference them: `s/(\d\d)_(\d\d)/$2 $1/`

Anchoring also works the same as Perl, such as `s/^FullNameMatch$/NewName/`. Other Perl regex features such as `\U` to upper-case are also supported.

Renex is built using **Boost-Regex**. You can refer to the [Boost-Regex 1.92 Syntax Documentation](https://www.boost.org/doc/libs/1_92_0/libs/regex/doc/html/boost_regex/syntax/perl_syntax.html) for full syntax details.

Moving files as a result of their new name is also supported, using `-allowMove`. Creating new folders can be enabled with `-createFolders`

Renex generates a log called `renex.log` of all rename operations along with commands to manually undo those renames.

## Examples

### Basic rename

Do a test run:

    renex "s/thing to replace/new thing/" *.doc

Review the output to see if the proposed renames are correct. Then append `-yes` or `-y` to your command to actually rename files:

    renex "s/thing to replace/new thing/" *.doc -yes

### Captures

Capture something with parens `()`. Reference it with a dollar-sign variable like `$1`.

Re-arrange dates in your filenames:

    renex "s/(\d\d)-(\d\d)-(\d\d\d\d)/$3-$2-$1/" *

### Modifiers

Renex supports the `g`, `i`, and `x` modifiers.

Remove all non-printable-ascii characters from your filenames:

    renex "s/[^\x20-\x7e]//g" *

### Processing File Extensions

Use the `-ext` option to include file extentions in the regex match.

Tidy up a folder of pictures with:

    renex "s/\.JPE?G$/.jpg/i" -ext *


### Processing Paths

Use the `-path` option to include file paths in the regex match.

Append the parent folder name to the filename:

    renex -path "s/\\([^\\]+)\\([^\\]+)$/\\$1\\$2_$1/" *

### Piping in Filenames to Process

You can use the `-stdin` option to read filenames from stdin. This can be used to recurse through directories or process filenames generated by other tools.

Change curly-braces on track numbers to square brackets with:

    dir /b /s *.flac | renex -stdin "s/{(\d+)}/[$1]/"

### Moving Files & Creating Folders

Use the `-allowMove` option to allow moving files to a different folder. Use the `-createFolders` option to create folders that don't exist.

Reorganize doc files into nested folders for year and date:

    renex "s/(\d\d\d\d)-(\d\d)-(\d\d)$/$1\\$2\\$1-$2-$3/" -allowMove -createFolders *.doc

## Usage

```
 Jargon Renex v1.0

    A utility for renaming files with regular expressions.
    https://github.com/jasonmray/JargonRenex/

 Usage:
    renex.exe [options] <regex> <source files...>

 Examples:
    renex.exe "s/ /-/g" *.mp4
    renex.exe "s/old/New/ig" *.docx
    renex.exe "s/(\d\d)-(\d\d)-(\d\d\d\d)/$3-$2-$1/" *
    renex.exe "s/[^\x20-\x7e]//g" *
    dir /b /s | renex.exe -stdin "s/(\d\d)/0$1/"
    dir /b /s | renex.exe -stdin -ext "s/^(\d\d)\.jpeg$/0$1.jpg/"
    renex.exe -allowMove -createFolders "s/(\w+)_(\w+)/$1\\$2/ig" *

 Notes:
    * Regex format is Perl-compatible, e.g. s/old/new/
    * Supported regex flags: [gix], e.g s/old/new/gix
    * By default, regex is only applied to the base filename of each file.
      Use the -path and -ext options to include file path and/or extension
      in processing.
    * By default, no files are renamed. Pass the -y option to rename files,
      or use -ask to get a confirmation prompt after reviewing the actions
      to be performed.

 General options:
    -h,-help               Show help screen and exit
    -v,-verbose            Verbose mode
    -q,-quiet              Quiet mode
    -c,-continueOnError    Continue processing files when certain errors are encountered.
    -y,-yes                Rename files without confirmation
    -a,-ask                Ask for confirmation before renaming
    -e,-ext                Include file extension in regex processing
    -p,-path               Include path in regex processing
    -m,-allowMove          Allow moving files to another folder
    -f,-createFolders      Create any necessary folders to move files
    -s,-stdin              Read filenames to process from stdin
    -n,-noLog              Don't create renex.log file

```

## Building

The project should build cleanly with Visual Studio 2022.
1. Unzip the dependencies by running `extract.bat` in the `external` folder
2. Open `JargonRenex.sln`
3. Build Release x64
4. Run `release.bat` in the root folder to collect the necessary binaries into a folder named `release`
